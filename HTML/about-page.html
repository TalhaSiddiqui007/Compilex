About CompileX

Write and run code in the browser, no setup required.

CompileX is a small practice project built by two people figuring out how an online compiler actually works — from spinning up language runtimes to getting code to run and return output in real time.

It's not a company or a product with a roadmap. It's a side project we're using to learn, break things, and rebuild them a bit better each time.

Built by

Two developers, one repo, and a lot of trial and error.
